💻 Computer Architecture Project

English Project - Class 2DS

About the Project

Exploring the fundamental components and architecture of modern computer systems.

This English project focuses on understanding how computers work at a fundamental level. We've researched and created presentations covering the main components of computer architecture, from the CPU to storage systems, and how they all work together to process information.

Through this project, we've learned technical vocabulary in English and gained a deeper understanding of the technology we use every day. Each presentation explores a different aspect of computer architecture, providing comprehensive insights into how modern computers function.
